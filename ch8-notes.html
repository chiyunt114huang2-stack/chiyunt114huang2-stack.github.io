📌 核心觀念提醒：連續型隨機變數的關鍵在於「機率 ＝ 曲線下的面積」，單一特定點的機率永遠為 $0$。計算均勻分配時只要掌握長方形的「底 × 高」就能輕鬆算出區間機率！

§8.1 連續隨機變數 (Random Variable)：間斷 vs 連續

(1) 間斷型 discrete r.v.

PMF
  • • 定義：$X$ 的可能值為可數的 (countable)，如人數、次數。
  • • 機率表達：機率質量函數 (probability mass function)。
  • • 例子 ($X$：進球數)：
    $x$ 0 1 2 3
    $P(x)$ $\frac{1}{8}$ $\frac{3}{8}$ $\frac{3}{8}$ $\frac{1}{8}$
    二項公式：$P(X=x) = C^n_x p^x (1-p)^{n-x}$

(2) 連續型 continuous r.v.

PDF
  • • 定義：$X$ 的可能值為不可數的 (uncountable)，如長度、重量、時間。
  • • 機率表達：機率密度函數 (probability density function)。
  • • 例子 ($X$：Louisa 等待時間 0~10 分)： ※ 無法用表格一一列舉所有小數時間，改以曲線下面積代表機率！
必背重點 機率密度函數 (PDF) 四大核心性質：
① 非負性：
$f(x) \ge 0$
② 總面積為 1：
所有面積相加 $= 1$
③ 點機率為 0：
單點無寬度，$P(X=c)=0$
④ 面積即機率：
$P(x_1 < X < x_2) = $ 區間面積

§8.1 均勻分配 (Uniform Distribution) $X \sim U(a, b)$

💡 均勻分配的意義： ① 隨機變數可能範圍為區間 $(a, b)$，其中 $a$ 為下界、$b$ 為上界； ② 在此區間內，每個等長小區間發生的可能性均等（高度處處相同）。
一般化均勻分配圖解
口訣：「均勻就是長方形，底乘高就搞定」
① PDF 高度
$$f(x) = \frac{1}{b - a}, \quad \text{for } a \le x \le b \quad (\text{其餘為 } 0)$$
② 區間機率
$$P(x_1 < X < x_2) = (x_2 - x_1) \times \frac{1}{b - a} = \frac{x_2 - x_1}{b - a}$$
③ 期望值
$$E[X] = \frac{a + b}{2}$$
🚇 課堂例題：等 MRT 時間 $X \sim U(0, 5)$

題目設定：假設捷運每 $5$ 分鐘一班，到達月台的等待時間 $X$ 服從 $0$ 到 $5$ 分鐘的均勻分配，即 $a = 0, \, b = 5$。

① 寫出機率密度函數 (PDF)：
$$f(x) = \begin{cases} \frac{1}{5 - 0} = \frac{1}{5}, & \text{for } 0 < x < 5 \\ 0, & \text{otherwise (區間外機率 }= 0\text{)} \end{cases}$$

② 求等待時間介於 $2$ 到 $4$ 分鐘的機率：
$$P(2 < X < 4) = \text{底} \times \text{高} = (4 - 2) \times \frac{1}{5} = \frac{2}{5} = 0.4$$

③ 平均等待時間 (期望值)： $E[X] = \frac{0 + 5}{2} = 2.5$ 分鐘。
