§8.1 連續隨機變數 (Random Variable)：間斷 vs 連續

(1) 間斷型 discrete r.v.

PMF
  • • 定義：$X$ 的可能值為可數的 (countable)，如人數、次數。
  • • 機率表達：機率質量函數 (probability mass function)。
  • • 例子 ($X$：進球數)：
    $x$ 0 1 2 3
    $P(x)$ $\frac{1}{8}$ $\frac{3}{8}$ $\frac{3}{8}$ $\frac{1}{8}$
    二項公式：$P(X=x) = C^n_x p^x (1-p)^{n-x}$

(2) 連續型 continuous r.v.

PDF
  • • 定義：$X$ 的可能值為不可數的 (uncountable)，如長度、重量、時間。
  • • 機率表達：機率密度函數 (probability density function)。
  • • 例子 ($X$：Louisa 等待時間 0~10 分)： ※ 無法用表格一一列舉所有小數時間，改以曲線下面積代表機率！
必背重點 機率密度函數 (PDF) 四大核心性質：
① 非負性：
$f(x) \ge 0$
② 總面積為 1：
所有面積相加 $= 1$
③ 點機率為 0：
單點無寬度，$P(X=c)=0$
④ 面積即機率：
$P(x_1 \lt X \lt x_2) =$ 區間面積

§8.1 均勻分配 (Uniform Distribution) $X \sim U(a, b)$

💡 均勻分配的意義： ① 隨機變數可能範圍為區間 $(a, b)$，其中 $a$ 為下界、$b$ 為上界； ② 在此區間內，每個小區間可能性均等（高度處處相同）。
一般化均勻分配圖解
口訣：「均勻就是長方形，底乘高就搞定」
① PDF 公式
$$f(x) = \frac{1}{b - a}, \quad \text{for } a \le x \le b$$
② 區間機率
$$P(x_1 \lt X \lt x_2) = (x_2 - x_1) \times \frac{1}{b - a} = \frac{x_2 - x_1}{b - a}$$
③ 期望值
$$E[X] = \frac{a + b}{2}$$
🚇 課堂例題：等 MRT 時間 $X \sim U(0, 5)$

① PDF：$f(x) = \frac{1}{5}$ for $0 \lt x \lt 5$（otherwise 為 $0$）。

② 求等待 $2$ 到 $4$ 分鐘機率：$P(2 \lt X \lt 4) = (4 - 2) \times \frac{1}{5} = \frac{2}{5}$。

③ 平均等待時間：$E[X] = \frac{0 + 5}{2} = 2.5$ 分鐘。

§8.2 常態分配 (Normal Distribution) $X \sim N(\mu, \sigma^2)$

📌 核心觀念：一般常態分配 $X \sim N(\mu, \sigma^2)$ 無法直接查表，必須先透過「平移 $\mu$，接著除 $\sigma$」進行標準化轉換成 $Z$ 分配，將中心點移至 $0$ 後即可查表求出機率！

1. 常態分配的意義

  • ① 中間值域發生機率較高。
  • ② 往兩側對稱遞減。
  • ③ PDF 呈現鐘型 (bell-shaped)。

2. 兩大參數特徵：$\mu$ 與 $\sigma$

① 參數：$\mu$ 決定中心點位置；$\sigma$ 決定分散程度。

$\sigma$ 較大 ➔ 圖形較矮胖
$\sigma$ 較小 ➔ 圖形較高瘦

② PDF 總面積 $= 1$，註記為：$X \sim N(\mu, \sigma^2)$

3. 常態分配的機率計算

$P(x_0 \le X \le x_1) \Rightarrow x_0$ 到 $x_1$ 之間的機率

計算方式：

  • ① 電腦程式算：Python、Excel、AI 工具。
  • ② 查表：先轉換為4. 標準常態分配 (Standard Normal Distribution, $Z$) 再查表。
☕ 5. 一般常態分配的機率：路易莎等待時間

已知 $X \sim N(5, 2^2)$（$\mu = 5, \, \sigma = 2$），求 $P(X \gt 6)$：

$$P(X \gt 6) = P\left(\frac{X - 5}{2} \gt \frac{6 - 5}{2}\right) = P(Z \gt 0.5)$$
💡 課堂重點：平移 $\mu$（中心點從 $5$ 移到 $0$），接著除 $\sigma$，即可轉為標準常態 $Z$！
📝 課堂例題：例題 8.4

已知 $X \sim N(32, 5^2)$（$\mu = 32, \, \sigma = 5$），求 $P(X \lt 40)$：

$$P(X \lt 40) = P\left(\frac{X - 32}{5} \lt \frac{40 - 32}{5}\right)$$ $$= P(Z \lt 1.6) = 0.9452$$
✔ 轉換為 $P(Z \lt 1.6)$ 後，考試時可直接查表得出 $0.9452$！
結論 一般常態分配標準化公式：$X \sim N(\mu, \sigma^2)$
$$P(X \lt x_0) = P\left(\underbrace{\frac{X - \mu}{\sigma}}_{\text{標準化 } Z} \lt \frac{x_0 - \mu}{\sigma}\right) = P\left(Z \lt \frac{x_0 - \mu}{\sigma}\right) \Longrightarrow \text{查表！}$$
