Continuous Probability Distributions（§8.1 連續隨機變數與均勻分配）

📝 隨堂筆記

§8.2 常態分配 (Normal Distribution) $X \sim N(\mu, \sigma^2)$

📌 解題口訣：一般常態分配 $X \sim N(\mu, \sigma^2)$ 無法直接查表，必須先透過「減平均 $\mu$、除以標準差 $\sigma$」進行標準化轉換成 $Z$ 分配，將中心點移至 $0$ 後即可查表求出機率！

1. 常態分配的意義

  • ① 中間值附近發生機率較高。
  • ② 往兩側對稱遞減（左右對稱）。
  • ③ PDF 呈現鐘型 (bell-shaped)。

2. 兩大參數特徵：$\mu$ 與 $\sigma$

① 參數決定形狀：$\mu$ 決定中心點位置；$\sigma$ 決定分散程度。

$\sigma$ 較大 ➔ 圖形較扁胖
$\sigma$ 較小 ➔ 圖形較瘦高

② PDF 總面積 $= 1$，標準數學註記為：$X \sim N(\mu, \sigma^2)$

3. 常態分配的機率計算方式

$P(x_1 \le X \le x_2) \Rightarrow x_1$ 到 $x_2$ 之間的曲線下面積

實務與考試求面積的兩大途徑：

  • ① 電腦程式計算：Python、Excel、AI 工具直接運算。
  • ② 標準化後查表：考試時將一般常態轉換為標準常態分配 (Standard Normal Distribution, $Z$) 再查表。
☕ 課堂範例 1：路易莎等待時間

已知等待時間 $X \sim N(5, 2^2)$（即 $\mu = 5, \, \sigma = 2$），求等待超過 $6$ 分鐘的機率 $P(X > 6)$：

$$P(X > 6) = P\left(\frac{X - 5}{2} > \frac{6 - 5}{2}\right) = P(Z > 0.5)$$
💡 步驟拆解：分子先減 $\mu=5$（中心點移至 $0$），分母再除以 $\sigma=2$（轉換為標準差單位），即可變成標準常態 $Z$！
📝 課堂範例 2：例題 8.4

已知 $X \sim N(32, 5^2)$（即 $\mu = 32, \, \sigma = 5$），求 $P(X < 40)$：

$$P(X < 40) = P\left(\frac{X - 32}{5} < \frac{40 - 32}{5}\right)$$ $$= P(Z < 1.6) = 0.9452$$
✔ 轉換出 $Z < 1.6$ 後，考試時可直接查標準常態分配表得出 $0.9452$！
考試必背結論 一般常態分配標準化公式：$X \sim N(\mu, \sigma^2)$
$$P(X < x_0) = P\left(\underbrace{\frac{X - \mu}{\sigma}}_{\text{標準化 } Z} < \frac{x_0 - \mu}{\sigma}\right) = P\left(Z < \frac{x_0 - \mu}{\sigma}\right) \Longrightarrow \text{直接查表！}$$
